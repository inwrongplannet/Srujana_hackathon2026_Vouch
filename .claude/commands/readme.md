# /readme

**Why this exists:** The README is what judges open first, and one controlled way to edit it keeps it clean
**Used by:** Everyone

Requested change: $ARGUMENTS

Follow the `readme-editor` skill. Only edit content between `<!-- BEGIN:x -->` and `<!-- END:x -->` markers; never add, remove or rename markers or touch text outside them. The `features` section is generated by `scripts/update_readme.py`, not typed by hand. Verify the quickstart against the Makefile, and run `make check` afterward if it covers README structure.
